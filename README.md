# zhandos-rybezh
# Linux файлдық құқықтар бойынша тапсырма

## (a) Қолданушылардың құқықтары:

Бастапқы құқықтар: `rw-r-----`

- Owner: оқу, жазу
- Group: оқу
- Others: құқық жоқ

## (b) chmod 750 data.txt орындалғаннан кейін:

Жаңа құқықтар: `rwxr-x---`

- Owner: оқу, жазу, орындау
- Group: оқу, орындау
- Others: құқық жоқ

## (c) Иесін және тобын өзгерту:

```bash
chown alice:staff data.txt
